#+title: Ahnaf Rafi's Dotfiles

This repository contains my configuration files.
The base system is Fedora Linux, starting from a minimal installation using the
Fedora Everything ISO from [[https://fedoraproject.org/misc/][https://fedoraproject.org/misc/]].
See the [[file:./setup-instructions.org][setup-instructions.org]] file to see how things are set up.

Ensure git is installed:
#+begin_src sh
sudo dnf install -y git
#+end_src
Backup an existing local dotfiles repository if needed:
#+begin_src sh
mv $HOME/dotfiles $HOME/dotfiles-bak
#+end_src
Clone this repository using
#+begin_src sh
# SSH:
git clone git@github.com:ahnaf-rafi/dotfiles.git $HOME/dotfiles
# HTTPS:
git clone https://github.com/ahnaf-rafi/dotfiles.git $HOME/dotfiles
#+end_src
The local stowrc is set up to stow ~$HOME/dotfiles/*~ correctly to the
appropriate subdirectories of ~$HOME~.
So, the dotfiles can be deployed using
#+begin_src sh
cd $HOME/dotfiles
stow .
#+end_src
